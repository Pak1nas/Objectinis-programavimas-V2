Ši programa gali apskaiciuoti studentu vidurkius bei medianas, juos išrušuoti pagal vardą, pavardę, vidurkį ir medianą. Duomeni galima ivesti ranka arba generuoti varda,pavardę/pažymius arba skaityti iš failo. Galima generuoti savo duomenų filus. Rezultatus galima išvesti į ekrana ir arba į faila kietekai/nuskriaustieji. Šioje programoje yra pilnai realizuoti įvesties/išvesties operatoriai bei "Rule of five" .

Norint pasileisti šią programą reikia turėti `g++` kompiliatorių, `make` programą, terminalą.
1. Klonuokite repozitoriją `git clone https://github.com/Augustas19/Objektinis-programavimas-2.git`
2. `mingw32-make programa`
3. `./programa` - bus paleista programa
4. `mingw32-make testas`
5. `./testai` - bus paleistas programos testavimas
6. `mingw32-make clean` - projekto išvalymas
